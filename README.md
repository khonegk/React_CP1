# React_CP1

Описание задания
Соберите компонент TaskBoard — список задач, объединяющий все темы раздела 1: типизацию props, JSX, композицию компонентов, условный рендеринг и рендеринг списков.

Требования к проекту
1. Типизированный интерфейс Task
Создайте interface Task с полями id (number), title (string), isCompleted (boolean).
2. Типизация props массива
Компонент TaskBoard принимает props с типом tasks: Task[] — массив задач, переданный явно с правильной типизацией.
3. Рендеринг через map() с корректным key
Список задач отображается через .map(). В качестве key используется task.id, а не index массива.
4. Обработка пустого списка
Если массив задач пуст, отображается отдельное сообщение (например, "Задач нет"), а не пустой список.
5. Условное визуальное отображение
Задачи с isCompleted: true визуально отличаются от незавершённых (например, через стиль text-decoration: line-through).
6. Композиция компонентов
TaskBoard использует отдельный дочерний компонент TaskItem для отображения одной задачи (минимум 2 компонента в композиции).
